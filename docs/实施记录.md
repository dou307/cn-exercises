## 接手顺序

先运行 `scripts/verify.py` 并查 `git status`。逐题审核时保存来源题块哈希、原答案、独立推导、模型前提、勘误与计分策略；不要直接改 vendor 原文。优先审第一章，再按用户学习需要推进。涉及来源变动时先冻结当前学习记录并设计 ID 迁移，不要重排后直接覆盖 `questions.json`。目前项目只本地使用，公开前必须解决来源授权。
