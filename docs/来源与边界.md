## 验证口径

六个 `chN/quiz.html` 页面实际有 641 个 `div.quiz-item`；来源 README 概述为 562 选择题 + 77 综合题 = 639，差 2。本站尚未查明 README 数字的历史统计口径，不能擅自将其中两个题块删除。557 个题块仅从单字母原答案及连续 A-D 四项结构判断可由程序自动比对；其他 84 个自评。自动比对不代表原答案正确。

`scripts/verify.py` 用独立 HTML 解析核对全部来源文件哈希、641 题完整文本哈希、题干/选项/答案文本、图片和表格单元格顺序及题内图片存在。题目内容迁移的完整性不等于原答案正确。第1～6章已逐题独立读题、检查来源答案/解析并查看图表，323题结论成立、270题附前提或解析提示、48题争议且不计分，见《全题库逐题审核》。尚未与扫描版王道原书或官方真题逐题对照，题中“统考真题”的年份和身份没有经官方原卷核实。发现截断图片、错配拓扑、模型不足等也作为争议标出，原文保持不动。

## 使用限制

这是本机个人学习网页。不要将 `vendor/`、`data/questions.json` 或其打包网站上传到公开仓库或部署平台。若未来公开，需要先确认题目、解析和插图的再分发授权，或换成明确允许公开使用的来源。浏览器记录属于用户资料，导入先完整校验并合并，重做追加历史；升级数据结构时应保留迁移脚本。地址栏中的 `?test=1` 使用独立测试记录空间，供浏览器验收使用。
