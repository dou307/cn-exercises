- 来源仓库没有 GitHub 标注的独立开源许可；README 明确“仅供个人学习备考使用，请勿商用或再分发”。本站仅在本机使用，不把其内容视为可公开再许可。
- 原始文件完整保存在 `vendor/kaoyan-408-networks/`，440 个文件；逐文件 SHA-256 在 `data/source-manifest.json`。提取数据在 `data/questions.json`，不替换原文。

## 验证口径

六个 `chN/quiz.html` 页面实际有 641 个 `div.quiz-item`；来源 README 概述为 562 选择题 + 77 综合题 = 639，差 2。本站尚未查明 README 数字的历史统计口径，不能擅自将其中两个题块删除。557 个题块仅从单字母原答案及连续 A-D 四项结构判断可由程序自动比对；其他 84 个自评。自动比对不代表原答案正确。

`scripts/verify.py` 独立核对全部来源文件哈希、每页题块数量、ID 唯一性与题内图片存在。尚未逐题将提取出的全文、表格、公式与扫描版王道原书对照；也没有独立复算原答案。来源页面若有错字、误标或解析争议，当前网页会保留该情况。题中标记为“统考真题”的年份和身份没有在本项目经官方资料核实。

## 使用限制

这是本机个人学习网页。不要将 `vendor/`、`data/questions.json` 或其打包网站上传到公开仓库或部署平台。若未来公开，需要先确认题目、解析和插图的再分发授权，或换成明确允许公开使用的来源。浏览器记录属于用户资料，导入先完整校验并合并，重做追加历史；升级数据结构时应保留迁移脚本。
