# 手机与电脑自动同步

网页保持 https://dou307.github.io/cn-exercises/ ，进度写入独立私有仓库 `dou307/cn-exercises-progress`，文件 `cn-progress-v1.json`。没有登录后台或公开的写入密钥。

## 首次连接

1. 在GitHub创建细粒度个人令牌，只选择 `cn-exercises-progress` 私有仓库，Repository permissions中的Contents设为Read and write。
2. 在电脑和手机分别打开网站，点右上角“设备同步”，填入此设备的令牌，点“连接并同步”。可为两个设备分别创建令牌。
3. 自己的设备可以勾选“记住连接”，以后重开浏览器继续同步；不勾选则只保留当前标签页会话。令牌直接填网页，不发给其他人。

首次连接会自动合并当前浏览器已有记录。之后作答或修改状态约2.5秒后同步，回到页面、恢复网络时同步；前台每分钟检查其他设备更新。手机后台的定时器可能暂停，回到前台会重新拉取。

同步范围：作答历史、最新自评、收藏/取消收藏、已学/取消已学、草稿/清空草稿。不同设备的不同作答都保留；同一字段的离线修改按修改时间选较新的版本，同毫秒冲突按固定值排序保证收敛，未提供草稿文本的逐字协同编辑。

本机保存和云端上传分开：断网/令牌过期/权限不足时仍可本机练习，页面显示未同步原因，连接恢复后重试。令牌权限可随时在GitHub撤销。断开连接不会清空任何学习记录。

凭据只保留在选择的浏览器存储中，不会放进题库、公开仓库、导出文件或私有进度文件。脚本每次同步确认目标为私有仓库；远端记录先完整校验再合并，SHA冲突会重新下载后重试，不直接覆盖。

## 验证

`node --test tests/state.test.cjs tests/sync.test.cjs` 覆盖离线合并、取消操作、清空草稿、自评更正、SHA冲突、损坏远端、公开仓库和离线失败。

`node scripts/check_sync_live.cjs` 使用本机已登录的gh凭据在进程内访问独立测试文件，验证两个客户端真实往返后清理该文件；不操作 `cn-progress-v1.json`，不把测试凭据保存到网站。
